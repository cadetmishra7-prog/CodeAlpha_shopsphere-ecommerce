# 🛒 ShopSphere - Full Stack Ecommerce Platform

A modern full-stack ecommerce application built with the MERN Stack.

## 🚀 Features

- User Authentication (JWT)
- User Registration & Login
- Admin Dashboard
- Product Management
- Shopping Cart
- Order Management
- Product Reviews
- Responsive UI
- Protected Routes
- MongoDB Database

## 🛠 Tech Stack

### Frontend
- React.js
- React Router
- Axios
- Bootstrap

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt

## Installation

### Clone Repository

```bash
git clone https://github.com/cadetmishra7-prog/shopsphere-ecommerce.git
```

### Backend

```bash
cd server
npm install
npm run dev
```

### Frontend

```bash
cd client
npm install
npm run dev
```

## Environment Variables

Create a `.env` inside the server folder.

```
PORT=5000
MONGO_URI=YourMongoDBURI
JWT_SECRET=YourSecret
```
